# OpAMP Service Provenance

The `opamp/` service currently remains an attributed fork of Lawrence OSS
rather than a fully renamed module.

Implications:

- Existing `github.com/getlawrence/lawrence-oss` module paths are preserved.
- Existing upstream copyright and `SPDX-License-Identifier: Apache-2.0`
  notices must remain intact.
- Functional changes should avoid removing upstream attribution.
- A future full rename may be planned separately if maintainers decide the
  migration cost is justified.
