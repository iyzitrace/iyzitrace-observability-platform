# Support

Use the following channels:

- Bugs: open a GitHub issue with reproduction steps.
- Questions: open a GitHub discussion when available, or use an issue marked
  `question`.
- Security: follow `SECURITY.md`; do not open public vulnerability reports.
- Commercial or private support: contact `support@iyzitrace.com`.

Maintainers prioritize security issues, reproducible bugs, release blockers,
and reviewed community pull requests.
